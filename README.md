# Fail2ban TUI 0.3

[English](README.en.md) · Русский

Цветная консольная панель Fail2ban для **Ubuntu 22.04 / 24.04**, Python 3.10+.
Без веб-сервера и сторонних Python-зависимостей.

```text
 F2B / 0.3.0                                                  RU · unicode
 ─────────────────────────────────────────────────────────────────────────
  Панель управления

  ● fail2ban: active · jail: 3 · сейчас в бане: 7 · всего банов: 335
  sshd 5 · nginx-http-auth 1 · recidive 1
  10-16 15:20:11  Ban    95.216.1.9  [sshd]  FI 🇫🇮
  10-16 15:19:02  Unban  8.8.4.4  [sshd]  US 🇺🇸

  > ◈  Обзор службы и jail
    ▣  Jail и их статус
    ⊖  Заблокированные IP · разбан
    ⊕  Заблокировать IP
    ⚙  Время блокировки и попытки
    ≡  Журнал Fail2ban
    ◉  Журнал в реальном времени
    ◍  Геобаза и поиск IP
    …
 ─────────────────────────────────────────────────────────────────────────
 ↑↓ выбор · Enter открыть · ESC назад · L язык · A значки · F флаги
```

Меню прокручивается; все пункты доступны и в небольшом терминале. Минимум
48×12, рекомендуется 100×26. Цвета отключаются, если терминал их не поддерживает.
Иконки Unicode не требуют Nerd Font. `A` переключает Unicode → **Nerd Font** → ASCII, `F` — флаги, `L` — RU/EN
(`sudo f2b --nerd` включает Nerd Font сразу).
Выбор сохраняется для сервера в `/var/lib/f2b-tui/preferences.json`.
ASCII относится к оформлению; для русского текста всё равно нужен UTF-8.
При проблемах с шрифтом: `sudo f2b --lang en --ascii`.

## Заблокированные IP, география и сети

Меню → **Заблокированные IP · разбан**:

```text
  Заблокированные IP · разбан
      CC IP-адрес          Jail            Осталось Сеть / провайдер
    ○ RU 77.88.8.8         nginx-http-auth  1м 24с AS13238 YANDEX LLC · 77.88.8.0/22  🇷🇺
  > ○ FI 95.216.1.9        sshd             4м 54с AS24940 Hetzner Online GmbH · 95.216.0.0/15  🇫🇮
    ○ DE 2a00:1450:4001::1 sshd             1д 23ч AS15169 Google LLC · 2a00:1450::/32  🇩🇪
```

| Клавиша | Действие |
|---|---|
| ↑↓ / j k / PgUp PgDn / Home End | перемещение |
| **Enter** | разбанить отмеченные (или выбранный) IP → `y` в этом jail, `a` во всех jail, `w` разбан + исключение |
| Пробел / `*` | отметить / отметить все видимые |
| `/` | поиск по IP, jail, стране, сети |
| `s` | сортировка: время, страна, сеть, jail, IP |
| `i` / `o` | подробности (офлайн) / уточнить город и сеть онлайн |
| `g` | сети, из которых забанено несколько IP (признак целевой атаки) |
| `b` | заблокировать IP вручную (loopback и ваш SSH-адрес отклоняются) |
| `r`, `?` | обновить сейчас (само каждые 5 с), помощь |

На главном экране показан дашборд: состояние службы, баны по jail, последние события
Ban/Unban. Есть журнал в реальном времени (как `tail -f`) с подсветкой Ban/Unban/Found.

`w` записывает `ignoreip` jail в `99-f2b-tui.local` тем же транзакционным путём, что и
остальные правки (копия → запись → проверка → reload → контроль → откат). Список исключений
этого jail фиксируется на текущем эффективном значении плюс новый IP.

**География.** Меню → *Геобаза* → *Обновить базу* скачивает CSV
[DB-IP Lite](https://db-ip.com/db/lite.php) (страна и ASN, ≈12 МБ, HTTPS) и атомарно
собирает `/var/lib/f2b-tui/geo.sqlite` (≈50 МБ). Сбой или отмена (ESC) оставляют прежнюю
базу. То же из консоли: `sudo f2b geo-update`, `sudo f2b geo-lookup 8.8.8.8 [--online]`.
Поиск локальный: адреса не покидают сервер. Городов в офлайн-базе нет (файл городов DB-IP
≈90 МБ в сжатом виде). По `o` или при поиске IP в меню Геобазы можно запросить город и имя сети
у **ipwho.is** и **rdap.org**, но только после вашего явного подтверждения; ответы
кэшируются на 30 дней (`geo-cache.json`, очищается из меню). Флаги выводятся в конце строки,
потому что терминалы по-разному считают их ширину; `F` их скрывает. Данные: © DB-IP.com, CC BY 4.0.

## Установка и переход с 0.1

Старая версия ещё не понимает `f2b update`: для первого обновления повторите
установку из нового репозитория. Существующие jail-файлы сохранятся.

```bash
sudo apt-get update
sudo apt-get install -y python3 fail2ban git
src=$(mktemp -d)
git clone --depth 1 https://github.com/barakov-dot/f2b-tui.git "$src"
git -C "$src" rev-parse HEAD
# Проверьте install.sh, f2b.py, f2b_core.py, f2b_geo.py, f2b_bans.py и f2b_ui.py в "$src".
sudo bash "$src/install.sh"
sudo f2b --lang ru
```

Для воспроизводимой установки используйте проверенный полный SHA коммита или
тег. `install-remote.sh [REF]` скачивает исходники **без root**, показывает SHA и
команду установки, сохраняет каталог для проверки. Без `--install` он ничего не устанавливает.
Под root можно поставить сразу, осознавая риск (лучше с закреплённым SHA/тегом):
`curl -fsSL …/install-remote.sh | bash -s -- REF --install`. Вариант `curl … | sudo bash` не поддерживается. Установщик не устанавливает пакеты сам, не меняет службу,
не перезаписывает `/etc/fail2ban` и отказывается заменять чужой `/usr/local/bin/f2b`.
Программа: `/opt/fail2ban-tui`; запуск: `/usr/local/bin/f2b`.

## Управление

- Стрелки / `j` / `k`, Home/End, PgUp/PgDn — навигация; Enter — открыть.
- **ESC отменяет любой ввод**, включая частично введённый IP, число и подтверждение.
  `q` выходит из меню и просмотра; внутри ввода это обычный символ.
- Бан одиночного IPv4/IPv6 требует `YES`; разбан из списка подтверждается одной клавишей (`y`/`a`/`w`).
- Просмотр логов: последние 250 строк; стрелки влево/вправо прокручивают длинные строки.
- Панель переводит свои подписи; диагностический вывод Fail2ban/systemd показывается как есть.

```bash
sudo f2b update                         # main; показывает SHA, спрашивает YES
sudo f2b update --ref FULL_COMMIT_SHA   # закреплённая версия
sudo f2b uninstall                      # подтверждение YES
sudo f2b backup                         # печатает ID
sudo f2b backups                        # список ID от новых к старым
sudo f2b restore BACKUP_ID              # подтверждение замены всей конфигурации
```

У `update`, `uninstall`, `restore` есть `--yes` для осознанной автоматизации.
`update` требует Git и HTTPS-доступ к GitHub. Проверяются сетевые ошибки и запуск
новой программы. Загруженный код выполняется с root после подтверждения; SHA
показывает выбранную версию, но не является независимой цифровой подписью.
Обновление скачивает файлы в отдельный временный каталог; прежняя программа
сохраняется до проверки новой. При ошибке установки выполняется откат программы.

## Сохранность конфигурации и восстановление

Перед изменением настроек, install/update/uninstall, reload/restart и восстановлением
создаётся полная копия `/etc/fail2ban` в `/var/lib/f2b-tui/backups/ID/config`.
Копии доступны только root, содержат секреты из исходных конфигов и автоматически
не удаляются. Следите за свободным местом. Если копирование не удалось, действие
не выполняется. Бан/разбан меняет состояние службы, а не конфигурацию: копия не
создаётся. База активных банов, firewall, журналы и внешние цели символических
ссылок не входят в резервную копию.

Параметры `bantime`, `findtime`, `maxretry` записываются только в
`/etc/fail2ban/jail.d/99-f2b-tui.local`. Другие jail-файлы не переписываются.
В управляемом файле сохраняются остальные секции/значения; форматирование и
комментарии могут нормализоваться. Целые значения: 1…31536000 (время — секунды).
Существующие конфиги могут содержать иные допустимые Fail2ban значения — панель
их не изменяет, пока вы сами не выберете этот параметр.

Порядок: проверка текущей конфигурации → копия → атомарная запись override →
`fail2ban-client -t` → reload → проверка фактического значения. Если поздний override
перекрывает параметр или проверка/reload завершается ошибкой, прежний override
восстанавливается побайтно и повторяется reload. Ошибка повторного reload явно
выводится вместе с ID копии: состояние работающей службы тогда нужно проверить
вручную. Одновременные изменения через несколько экземпляров панели блокируются;
во время операции не редактируйте конфиги другими средствами.

Восстановление **заменяет всю `/etc/fail2ban`**, предварительно сохраняет текущую
конфигурацию и проверяет выбранную копию; при ошибке возвращает предыдущую.
Это откат файлов конфигурации, не состояния банов. Импорт произвольных архивов не
поддерживается. Не используйте `/etc/fail2ban` как symlink или отдельную точку
монтирования для операции восстановления. При выключении питания / SIGKILL
между переименованиями каталогов автоматический откат не гарантируется; копии
сохраняются для ручного восстановления. Перед восстановлением оцените, какие
jail будут включены выбранной копией.

Удаление убирает только программу и принадлежащую ей ссылку запуска. Fail2ban,
`99-f2b-tui.local`, пользовательские конфиги, настройки языка и резервные копии
остаются. Неизвестные файлы в каталоге программы не удаляются.
После удаления для восстановления копии можно повторно установить панель.

## Проверки

```bash
python3 -m unittest discover -s tests -v
bash -n install.sh install-remote.sh uninstall.sh
# Только Linux/root, с установленным Fail2ban; отдельный демон без firewall actions:
sudo python3 tests/integration_linux.py
```

CI запускает тесты на Ubuntu 22.04 и 24.04. Проверяются отмена ввода, маленький
терминал, обе локали, сохранность jail-файлов, ошибки валидации/reload/установки,
реальные ban/unban IPv4/IPv6, изменение и восстановление настроек.
